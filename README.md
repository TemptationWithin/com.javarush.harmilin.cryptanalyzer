Technical task
Develop a program that allows encryption and decryption of text using the Caesar cipher. The program must support several modes of operation, ensure the processing of large files and have validation of input data. Optionally, you can add a graphical user interface, as well as statistical analysis for automatic cracking of the cipher.

Main tasks:

Implementation of the Caesar cipher:

Creation and use of the alphabet.
Algorithm for shifting characters according to a given key.
File processing:

Functionality for working with files (reading, writing).
Processing large text files.
Input validation:

Checking the existence of files.
Acceptability of keys.
Operating modes:

Text encryption:

Encryption function that accepts a file, a key and writes the encrypted text to a new file.
Text decryption:

Decryption function using a known key.
Brute force decryption (optional):

Implementation of brute force method to try all keys until successful decryption.
Statistical analysis decryption (optional):

Development of statistical analysis algorithm for automatic decryption without key, using language features.
Development of user interface:

Text menu or (optional) graphical interface
